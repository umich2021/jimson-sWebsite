4 style directions

  • 1. Stripe — gradient, soft, colorful
    Purple/pink gradient mesh hero, rounded cards, gradient-text headline. Polished SaaS feel.
  • 2. Linear — dark, minimal, technical
    Dark mode, monospace labels, subtle grid background, violet accent. Product/engineering feel.
  • 3. Vercel — black & white, sharp
    Pure black background, hairline grid dividers, uppercase mono labels, centered hero.
  • 4. Editorial — warm, serif, personal
    Cream background, serif headings, timeline experience section. Feels more human/writerly.
  • 5. Game HUD — RPG stats screen
    No header/hero at all. Player card, XP bar, quest log (experience), inventory (projects), achievement unlock (education), dialogue-choice contact box, hotbar nav.
  • 6. Desktop OS — click-to-open windows
    No nav either. Menu bar, desktop icons, draggable windows (About, Aventos, Projects, Experience, Education, Contact), dock at bottom.
