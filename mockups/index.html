Mockups

  • Game — challenge select screen
    Title screen, then a level-select grid of 5 sections. Pick one and a color-wipe transition (themed to that section) drops you into a different mini-game per section: catch falling frames (Aventos), walk a quest path (Experience), crack open loot chests (Projects), answer a quiz (Education), or a dialogue choice (Contact).
  • Desktop OS — click-to-open windows
    Menu bar, desktop icons, draggable windows (mouse or touch) for About, Aventos, Projects, Experience, Education, Contact, plus a dock. Responsive on mobile.
