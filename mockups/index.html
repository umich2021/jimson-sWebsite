Mockups

  • Game — tag-based (no lens picker)
    Title → level-select grid of 5 sections. All real content is visible immediately in every section; mini-games (catch, quest walk, loot vault, potion brew) are optional toys, not gates. Experience/Projects entries carry color-coded skill tags (Engineering / GTM / Founder) to separate the mixed skillset.
  • Game — lens picker version
    Same as above, plus a ‘what are you evaluating me for?’ screen right after the title (Engineering / GTM-Growth / Generalist, mirroring the real JobsHub page). Picking a lens de-emphasizes less-relevant experience entries; skippable to see everything.
  • Desktop OS — click-to-open windows
    Menu bar, desktop icons, draggable windows (mouse or touch) for About, Aventos, Projects, Experience, Education, Contact, plus a dock. Auto-opens a landing window, visible × to close, dock tooltips, click-to-toggle. Responsive on mobile.
